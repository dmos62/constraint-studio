02 / UNDER THE HOOD

Layout is the
equation.

Instead of mapping a pointer delta directly to CSS, we ask the browser which CSS value satisfies the shape you draw.

01

Set a target

Dragging a handle establishes the frame’s desired width and height.

02

Measure candidate states

The actual heading, in its real container, is measured using getBoundingClientRect().

03

Solve, then apply

The largest fitting font size is found and written to a CSS custom property. The underlying state is serializable.
